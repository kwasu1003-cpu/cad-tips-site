인터넷에서 받은 LISP 파일이나 동료가 준 `.lsp` 파일을 CADian에서 쓰려면 먼저 불러온(로드) 뒤 명령 이름을 입력해야 합니다. 이 글에서는 **CADian에서 LISP 파일을 불러오는 세 가지 방법과 실행하는 법**, 매번 불러오기 귀찮을 때 쓰는 자동 로드 설정까지 예제 루틴 하나로 따라 해 봅니다. 기준 버전은 CADian 2022이고 내용은 CADian 도움말의 "LISP 루틴 사용" 항목을 바탕으로 했습니다.

## CADian과 LISP의 관계

CADian은 IntelliCAD 엔진을 쓰는 CAD이고 AutoCAD의 AutoLISP와 호환되는 LISP를 지원합니다. 그래서 AutoCAD용으로 만든 LISP 루틴도 대부분 그대로 불러와 쓸 수 있습니다. 다만 AutoCAD 전용 기능(일부 `vla-` 함수나 대화상자 정의 등)을 쓰는 루틴은 동작이 다를 수 있으니 처음 쓰는 루틴은 빈 도면에서 먼저 시험해 보는 편이 안전합니다.

## 따라 할 예제 루틴 만들기

불러오기를 연습할 파일부터 하나 만듭니다. 메모장을 열고 아래 내용을 붙여 넣은 뒤 `D:\lisp\rectwh.lsp`로 저장합니다(폴더는 아무 곳이나 괜찮습니다).

```lisp
;; RECTWH : 기준점, 가로, 세로를 입력받아 사각형 폴리선을 그린다
(defun c:RECTWH (/ p w h old)
  (setq p (getpoint "\n왼쪽 아래 기준점: "))
  (setq w (getdist p "\n가로 길이: "))
  (setq h (getdist p "\n세로 길이: "))
  (setq old (getvar "OSMODE"))
  (setvar "OSMODE" 0)                       ; 객체 스냅이 점을 끌어가지 않게 잠시 끔
  (command "_.PLINE"
           p
           (list (+ (car p) w) (cadr p))
           (list (+ (car p) w) (+ (cadr p) h))
           (list (car p) (+ (cadr p) h))
           "_C")
  (setvar "OSMODE" old)                     ; 원래 스냅 설정으로 되돌림
  (princ (strcat "\n면적: " (rtos (* w h) 2 2)))
  (princ)
)
```

`defun c:RECTWH`처럼 이름 앞에 `c:`가 붙은 함수가 명령어로 등록됩니다. 불러온 뒤 명령줄에 `RECTWH`만 입력하면 실행되는 이유가 이것입니다. 대소문자는 구분하지 않습니다.

저장할 때 메모장의 인코딩은 기본값(UTF-8)으로 두어도 되지만 프롬프트의 한글이 깨져 보이면 ANSI로 다시 저장해 보세요.

## 방법 1. APPLOAD 대화상자로 불러오기

가장 기본적인 방법입니다.

1. 명령줄에 `APPLOAD`를 입력하고 Enter를 누릅니다. 메뉴의 **도구 > 응용 프로그램 로드**나 리본의 같은 항목을 눌러도 됩니다.
2. "응용 프로그램 파일 로드" 대화상자에서 **파일 추가**를 누릅니다.
3. `D:\lisp\rectwh.lsp`를 고르고 **열기**를 누릅니다.
4. 목록에서 방금 추가한 파일만 선택된 상태인지 확인하고 **로드**를 누릅니다.

로드가 끝나면 명령 모음(또는 프롬프트 기록 창)에 파일 경로와 함께 `C:RECTWH` 같은 줄이 보입니다. `C:` 뒤에 나온 이름이 바로 실행할 명령입니다. 남이 만든 루틴이라 명령 이름을 모를 때는 이 줄을 찾아보면 됩니다. 명령 모음이 안 보이면 **보기 > 표시**에서 명령 모음이나 프롬프트 기록 창을 켭니다.

## 방법 2. 파일을 끌어다 놓기

탐색기에서 `.lsp` 파일을 CADian 도면 창으로 끌어다 놓아도 로드됩니다. 한두 번 써 볼 루틴이라면 이 방법이 가장 빠릅니다.

## 방법 3. 명령줄에 load 함수 입력

명령줄에 괄호와 따옴표까지 포함해 아래처럼 입력합니다.

```lisp
(load "D:/lisp/rectwh.lsp")
```

여기서 자주 틀리는 부분이 경로 구분 기호입니다. LISP 문자열 안에서 역슬래시(`\`)는 특수 문자로 해석되므로 경로를 그대로 붙여 넣으면 파일을 찾지 못합니다. 둘 중 하나로 씁니다.

| 쓰는 법 | 예 | 결과 |
|---|---|---|
| 슬래시 | `"D:/lisp/rectwh.lsp"` | 로드됨 |
| 역슬래시 두 번 | `"D:\\lisp\\rectwh.lsp"` | 로드됨 |
| 역슬래시 한 번 | `"D:\lisp\rectwh.lsp"` | `\r`이 제어 문자로 해석되는 등 경로가 바뀌어 실패 |

탐색기 주소창에서 복사한 경로는 역슬래시가 한 번씩이니 붙여 넣은 뒤 꼭 고쳐야 합니다.

## 불러온 루틴 실행하고 결과 검산하기

로드가 끝났으면 명령줄에 `RECTWH`를 입력합니다. 예제로 기준점 `0,0`, 가로 `200`, 세로 `100`을 넣어 보겠습니다.

| 꼭짓점 | 계산식 | 좌표 |
|---|---|---|
| 1 | 기준점 | (0, 0) |
| 2 | (0 + 200, 0) | (200, 0) |
| 3 | (0 + 200, 0 + 100) | (200, 100) |
| 4 | (0, 0 + 100) | (0, 100) |

명령줄에는 `면적: 20000.00`이 찍혀야 합니다. 200 × 100 = 20,000이므로 맞습니다. 그려진 사각형을 `LIST` 명령으로 선택해 보면 면적 20000, 둘레 600(= 2 × (200 + 100))이 나오는지 한 번 더 확인할 수 있습니다.

LISP 루틴 안에서 `command` 함수로 점을 찍을 때 객체 스냅이 켜져 있으면 근처의 다른 객체로 점이 끌려가 치수가 틀어질 수 있습니다. 예제에서 `OSMODE`를 잠시 0으로 바꿨다가 되돌린 것은 그 때문입니다. 받아 쓴 루틴이 가끔 엉뚱한 곳에 선을 그린다면 이 부분부터 의심해 보세요.

## CADian을 켤 때 자동으로 불러오기

자주 쓰는 루틴을 매번 APPLOAD로 불러오기는 번거롭습니다. CADian은 정해진 이름의 LISP 파일을 시작할 때 자동으로 읽습니다.

| 파일 이름 | 읽는 시점 |
|---|---|
| `ICAD.LSP` | CADian을 시작할 때 한 번 |
| `ICADDOC.LSP` | 도면을 새로 만들거나 열 때마다 |

설정 순서는 이렇습니다.

1. 메모장으로 새 파일을 만들고 불러올 루틴마다 한 줄씩 `load` 문을 적습니다.

   ```lisp
   (load "D:/lisp/rectwh.lsp")
   (load "D:/lisp/dimfix.lsp")
   ```

2. 파일 이름을 `ICAD.LSP`(또는 `ICADDOC.LSP`)로 저장합니다.
3. CADian 실행 파일(`Icad.exe`)이 있는 폴더에 넣습니다. 기본 설치라면 `C:\CADian\CADian 2022` 같은 폴더입니다.
4. CADian을 다시 실행하고 명령줄에 `RECTWH`를 입력해 바로 실행되는지 확인합니다.

참고: 설치 폴더 위치에 따라 파일을 넣을 때 관리자 권한을 요구할 수 있습니다. 루틴 파일 자체는 `D:\lisp`처럼 따로 관리하고 `ICAD.LSP`에는 `load` 줄만 두면 CADian을 다시 설치해도 이 파일 하나만 옮기면 됩니다.

도면을 여러 개 열었을 때 모든 도면이 같은 LISP 변수와 함수를 함께 쓰게 하려면 시스템 변수 `LISPINIT`를 2로 설정합니다.

## 안 될 때 확인할 것

| 증상 | 확인할 것 |
|---|---|
| 명령을 입력해도 알 수 없는 명령이라고 나옴 | 로드했는지, 로드 메시지의 `C:` 뒤 이름과 같은지 |
| `load`에서 파일을 못 찾음 | 경로의 역슬래시를 `/`나 `\\`로 바꿨는지, 확장자까지 적었는지 |
| 로드는 되는데 실행 중 멈춤 | 괄호 짝이 맞는지, AutoCAD 전용 함수를 쓰는지 |
| 자동 로드가 안 됨 | 파일 이름이 정확히 `ICAD.LSP`인지(`ICAD.LSP.txt`가 아닌지), `Icad.exe`와 같은 폴더인지 |
| 점 위치가 조금씩 틀어짐 | 루틴 실행 중 객체 스냅이 켜져 있는지 |

메모장으로 저장하면 탐색기에서 확장자가 숨겨져 `ICAD.LSP.txt`가 되는 경우가 많습니다. 탐색기 **보기** 메뉴에서 파일 확장명을 켜 두면 바로 알 수 있습니다.

## 정리

- 한 번 쓸 루틴은 끌어다 놓기, 자주 쓰는 루틴은 APPLOAD나 `(load "D:/경로/파일.lsp")`로 불러온다
- 불러온 뒤에는 로드 메시지의 `C:` 뒤 이름을 명령줄에 입력해 실행한다
- 매번 쓰는 루틴은 `ICAD.LSP`에 `load` 줄을 적어 `Icad.exe` 폴더에 두면 시작할 때 자동으로 불러온다

다음 글에서는 도면 파일 이름 규칙을 정하고 파이썬으로 한 번에 바꾸는 방법을 정리해 보겠습니다.
