견적서를 쓰거나 운반·포장 무게를 정할 때 부품 중량을 매번 계산기로 구하면 시간이 걸리고 단위 실수도 잦습니다. 이 글에서는 **재질과 치수만 넣으면 중량이 자동으로 나오는 엑셀 계산표**를 처음부터 만들어 봅니다. 판재, 환봉, 판금 전개품을 한 표에서 계산하고 구멍 공제와 수량 합계까지 넣습니다.

## 중량 계산의 기본 공식

중량은 부피에 밀도를 곱한 값입니다. 도면 치수는 mm, 밀도는 보통 g/cm³로 쓰기 때문에 단위만 맞추면 됩니다.

```
중량(kg) = 부피(mm³) × 밀도(g/cm³) ÷ 1,000,000
```

1 cm³는 1,000 mm³이고 1 kg은 1,000 g이므로 두 번 나누어 1,000,000이 됩니다. 이 숫자 하나만 기억하면 엑셀 수식이 아주 짧아집니다.

형상별 부피는 다음처럼 구합니다.

| 형상 | 부피(mm³) |
|---|---|
| 판재 | 두께 × 가로 × 세로 |
| 환봉 | π × (지름/2)² × 길이 |
| 판금 전개품 | 두께 × 전개 길이 × 폭 |
| 구멍(공제) | π × (구멍 지름/2)² × 두께 × 개수 |

## 1단계: 재질 목록 시트 만들기

먼저 `재질`이라는 시트를 만들고 자주 쓰는 재질과 밀도를 적어 둡니다. 계산 시트는 이 목록에서 밀도를 찾아오기만 합니다.

| A (재질) | B (밀도 g/cm³) |
|---|---|
| SS400 | 7.85 |
| SUS304 | 7.93 |
| AL5052 | 2.68 |
| AL6061 | 2.70 |

> 확인 필요: 위 밀도 값은 일반적으로 쓰는 값입니다. 회사 견적 기준이나 소재 업체 성적서 값이 있으면 그 값으로 바꿔 쓰세요.

밀도를 수식 안에 숫자로 박아 두지 않고 표로 따로 두는 이유는 간단합니다. 기준값이 바뀌어도 이 표 한 칸만 고치면 모든 계산이 따라 바뀝니다.

## 2단계: 계산 시트 열 구성

`계산` 시트의 1행에 아래 제목을 넣습니다.

| 열 | 제목 | 입력/수식 |
|---|---|---|
| A | 품명 | 입력 |
| B | 형상 | 입력 (판재 / 환봉 / 판금) |
| C | 재질 | 입력 |
| D | 두께 또는 지름 | 입력 |
| E | 가로 또는 길이 | 입력 |
| F | 세로 또는 폭 | 입력 (환봉은 비움) |
| G | 구멍 지름 | 입력 (없으면 비움) |
| H | 구멍 개수 | 입력 (없으면 0) |
| I | 밀도 | 수식 |
| J | 단품 중량(kg) | 수식 |
| K | 수량 | 입력 |
| L | 합계 중량(kg) | 수식 |

판금 전개품은 E열에 전개 길이를 넣습니다. 전개 길이 계산은 [판금 전개 길이, 엑셀로 자동 계산하기](/posts/sheetmetal-flat-length-excel/) 글의 표를 그대로 이어 쓰면 됩니다.

## 3단계: 수식 넣기

**밀도(I2)** 는 재질 시트에서 찾아옵니다.

```
=VLOOKUP(C2, 재질!$A:$B, 2, FALSE)
```

마지막 인수 `FALSE`는 정확히 같은 이름만 찾으라는 뜻입니다. 재질 이름에 오타가 있으면 `#N/A`가 나오니 틀린 값이 조용히 들어가는 일이 없습니다.

**단품 중량(J2)** 은 형상에 따라 부피 식을 고릅니다.

```
=IF(B2="환봉", PI()*(D2/2)^2*E2,
    D2*E2*F2 - PI()*(G2/2)^2*D2*H2) * I2 / 1000000
```

판재와 판금은 계산 방식이 같아서 한 식으로 묶었습니다. 구멍이 없으면 H2가 0이라 공제 항이 0이 됩니다. 엑셀에서는 위 수식을 한 줄로 이어서 입력합니다.

**합계 중량(L2)** 은 단품 중량에 수량을 곱합니다.

```
=J2*K2
```

표 맨 아래에는 전체 합계를 둡니다.

```
=SUM(L2:L100)
```

## 예제와 검산

네 가지 부품을 넣어 보겠습니다.

| 품명 | 형상 | 재질 | D | E | F | 구멍 | 수량 |
|---|---|---|---|---|---|---|---|
| 베이스판 | 판재 | SS400 | 3 | 200 | 150 | Ø10 × 4 | 4 |
| 축 | 환봉 | SUS304 | 20 | 100 | | | 2 |
| 커버 | 판재 | AL5052 | 2 | 300 | 200 | | 1 |
| ㄱ자 브래킷 | 판금 | SS400 | 2 | 76.40 | 40 | | 10 |

손으로 하나씩 검산해 보면 다음과 같습니다.

1. 베이스판
   - 판 부피 = 3 × 200 × 150 = 90,000 mm³
   - 구멍 부피 = 3.1416 × 5² × 3 × 4 = 942.48 mm³
   - 중량 = (90,000 − 942.48) × 7.85 ÷ 1,000,000 = **0.6991 kg**
2. 축
   - 부피 = 3.1416 × 10² × 100 = 31,415.9 mm³
   - 중량 = 31,415.9 × 7.93 ÷ 1,000,000 = **0.2491 kg**
3. 커버
   - 부피 = 2 × 300 × 200 = 120,000 mm³
   - 중량 = 120,000 × 2.68 ÷ 1,000,000 = **0.3216 kg**
4. ㄱ자 브래킷 (전개 길이 76.40은 앞 글의 예제 값)
   - 부피 = 2 × 76.40 × 40 = 6,112 mm³
   - 중량 = 6,112 × 7.85 ÷ 1,000,000 = **0.0480 kg**

합계는 0.6991 × 4 + 0.2491 × 2 + 0.3216 × 1 + 0.0480 × 10 = **4.096 kg**입니다. 엑셀 표의 합계 칸도 같은 값이 나오면 수식이 제대로 들어간 것입니다.

구멍 공제가 얼마나 영향을 주는지도 볼 만합니다. 베이스판의 구멍 네 개는 약 0.0074 kg으로 판 무게의 1% 남짓입니다. 견적용이라면 생략해도 되지만 구멍이 많은 타공판은 차이가 커지므로 공제 열을 남겨 두는 편이 좋습니다.

## 실무에서 쓰기 좋게 다듬기

계산표를 오래 쓰려면 몇 가지를 더 해 두면 편합니다.

- **재질 입력을 목록으로 제한**: C열을 선택하고 데이터 → 데이터 유효성 검사 → 목록에서 원본을 `=재질!$A$2:$A$20`으로 지정합니다. 오타로 `#N/A`가 나는 일이 거의 사라집니다.
- **형상 입력도 목록으로**: B열에 `판재,환봉,판금`을 목록으로 넣어 두면 IF 조건과 글자가 어긋나지 않습니다.
- **오류 대신 빈칸 보이기**: 아직 입력하지 않은 줄에 오류가 보기 싫으면 J2를 `=IFERROR(위 수식, "")`로 감쌉니다. 다만 재질 오타까지 숨겨지니 처음 만들 때는 감싸지 않고 확인하는 것이 낫습니다.
- **소수 자리 맞추기**: 중량 열은 셀 서식에서 소수 셋째 자리까지만 보이게 합니다. 계산은 원래 값으로 하므로 합계가 틀어지지 않습니다.
- **표로 변환**: 범위를 선택하고 Ctrl+T로 표를 만들면 새 줄을 넣을 때 수식이 자동으로 채워집니다.

## 자주 하는 실수

| 증상 | 원인 | 해결 |
|---|---|---|
| 중량이 1,000배 크게 나옴 | ÷ 1,000,000 대신 ÷ 1,000 | 단위 식을 다시 확인 |
| `#N/A` | 재질 이름 오타, 앞뒤 공백 | 유효성 검사 목록 사용, `TRIM` |
| 환봉 중량이 0 | B열이 "환봉"이 아니라 "봉" 등으로 입력됨 | 형상도 목록으로 제한 |
| 판금 중량이 큼 | 전개 길이 대신 바깥 치수 합을 넣음 | 전개 길이(BD 뺀 값)를 넣음 |

## 정리

- 중량(kg) = 부피(mm³) × 밀도(g/cm³) ÷ 1,000,000 하나만 기억하면 됩니다.
- 밀도는 재질 시트에 따로 두고 VLOOKUP으로 불러와야 기준이 바뀌어도 한 곳만 고칩니다.
- 판금은 전개 길이로, 구멍은 공제 열로 계산하면 견적용 중량이 충분히 정확해집니다.
